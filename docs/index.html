5HKR

Shaker. Perc groove box.

Eight synth lanes on a 16th-note grid, pattern banks, per-lane swing and loop length, and a sidechain duck. Not a sample player.

Download GitHub

VST3 and standalone. Hold C1 for bank 1 pattern 1 (Ableton C0), like TEW03.

Main

CHH, OHH, Crash, Cym, Shaker, Clave, Cow, Rim. Click a cell off → on (cyan) → accent (magenta). Right-click sets that lane’s loop end. Tune ±12 st and swing per lane. Length 1 / 2 / 4 bars.

Sidechain

Ducks the lanes from the plugin audio input. Sidechain off by default. HP / LP pick the key, Listen previews it. Thresh, Amount, Attack, Release, Mix. Title bar chevrons cycle Main and Sidechain. Click 5HKR for About.
