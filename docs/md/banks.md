# Banks

Every slot starts with its own one-bar groove. **Init Bank** restores them if you have made a mess you no longer want to own. Pattern 12 in each bank is a fill.

- **Bank 1** — house / techno, straight: offbeat hats, rolling 16ths, shaker-led, tribal, breakdown, peak time. The “put it on a kick and go” bank.
- **Bank 2** — latin / afro: son and rumba clave, cascara, mambo bell, bembe, samba, baiao, afrobeat, songo. Add lane swing to taste. The grid is still sixteenths; the feel is not.
- **Bank 3** — broken / polyrhythmic: short lane loops (3, 5, 6, 7, 9, 11, 13 steps) that drift against the bar, displaced hats, ghost rims. For when even is too even.

Saved sessions and `.5hkrb` banks keep their own patterns, so factory is a starting point, not a prison.
