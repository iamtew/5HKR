# Sidechain

Ducks the mixed lanes from the plugin audio input. **Sidechain** is off until you turn it on, which is a kindness: a ducker that starts hungry will eat the first bar of a demo and then you will write a bug report.

**HP** / **LP** isolate the part of the input the ducker follows. **Listen** puts that filtered key on the output so you can hear it. Standalone can feed back if a live mic is the input, so maybe do not Listen at a festival. Then Thresh, Amount, Attack, Release, Mix. The plot under the knobs is that filtered key; cyan lines mark HP / LP.
