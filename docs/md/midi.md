# MIDI

Hold C1 for bank 1 pattern 1. Ableton will call that C0, because Ableton. C2 is bank 2 pattern 1. Mapping starts at MIDI note 24; 36 slots, one per pattern across the three banks.

Hold C3 (note 60) for the bank’s fill (pattern 12) while a pattern key is held, or while standalone Play is running.

VST3 follows host BPM. Standalone uses the Tempo parameter, which is 120 unless you automate it into something more exciting.
