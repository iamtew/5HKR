# Mixer

One strip per lane. This is the “make it sit in the track” page, not the “invent a new drum” page.

**Gain** is trim (±12 dB). **High / Mid / Low** is a 3-band EQ, and no, it is not the post EQ page — that one comes later and is much fancier about it. **Filter** is a DJ filter: left high-pass, centre off, right low-pass. **Pan** is constant-power.

The speaker is the same mute as **M** on Main. No new hits; ringing tails keep going, which is the polite way to mute a cymbal. **S** solos that lane. The fader cap sets channel level; the thin bar behind it is that lane’s meter. Edit **Level** still shapes the synth. Master volume stays in the title bar, where you left it.

If the DAW shows extra plugin outputs, buses **CHH** … **Rim** are that strip after pan — no master volume, no FX, no post EQ, no duck. The main **Output** is still the full mix. A lane with FX send at 100% is wet-only on the master and still dry on its own bus, which is either a feature or a prank depending on the session.
