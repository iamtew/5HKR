# Hello, shaker

5HKR is a percussion overlay. Eight analog-ish synth lanes sit on a sixteenth grid, with banks you can key-lock the same way as TEW03. Hold a mapped MIDI key and the groove runs. Let go, and it stops being polite about occupying the mix.

Each lane can play its synth kit, or one dropped one-shot instead. That is not a sample library. One file, mono, trimmed to four seconds, saved in the patch. Mix kits across lanes if you like: 808 hats over a Linn rim is a perfectly legal life choice.

This is the user book. Internals live under Spec, Architecture, and DSP notes in the sidebar, if you enjoy reading the wiring.

VST3 and standalone. Windows, Linux, and Mac.

## Pages

The title bar is **Main / Mixer / Effects / EQ / Sidechain**. Chevrons cycle them, or click the name.

Click **5HKR** plus the version in the top left for About. **Check for update** looks at GitHub tags; if a newer build exists, **Open releases** takes you to the download page.

**Volume** lives on the right of the title bar: master fader and a peak meter from −48 dB to 0 dB that holds the hit. Clip lights if the output kisses 0 dBFS.

Drag the window corner to scale. The scale is saved with the session, so you do not have to rediscover your favourite size every Tuesday.
